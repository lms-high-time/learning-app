Как подключить в Claude Desktop

  1. Settings → Connectors → Add custom connector.
  2. Name — любое, URL — адрес из блока выше. Поля OAuth оставьте пустыми.
  3. В открывшемся окне войдите на этот сайт своей учётной записью и подтвердите доступ.
  4. При первом вызове инструмента разрешите его: Allow always.

Другие MCP-клиенты (Claude Code, Cursor) подключаются тем же адресом через OAuth.

Ограничение: не больше {{ registration_limit }}. Каждое новое подключение регистрирует клиента заново, так что не переподключайте коннектор без нужды.
